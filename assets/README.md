# WA Status Downloader assets

Runtime assets are organized by purpose:

```text
assets/
├── icon/           # Current WA icon masters and store icon rasters
├── onboarding/     # First-run illustrations
├── empty/          # Empty and access-state illustrations
├── illustrations/  # Save and privacy feedback artwork
├── fonts/          # Bundled Plus Jakarta Sans font
└── store/          # Store listing artwork and screenshot guidance
```

`assets/icon/launcher_icon.png` is the text-free launcher master used to derive Android and iOS launcher resources. `assets/icon/logo_full.png` is used by the in-app brand component.

The obsolete copied brand directories and their generated documentation assets were removed. Do not add product or publisher marks from another project.
